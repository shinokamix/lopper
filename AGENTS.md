# lopper

Read [CONTRIBUTING.md](CONTRIBUTING.md) before changing anything — it applies to
agents too. On top of it:

- Never open a PR unless the developer asks for one.

## Comments

- Comment only to say why, when the code cannot show it, such as a security
  reason, an invariant or a workaround for an old git. Never restate the code,
  as in "noteSep separates the notes of a row".
- revive requires doc comments on exported names. Say only what the signature
  does not.
- Write short, whole sentences in the active voice, with no em dashes or
  parentheses and a colon only before a list.
- Keep the task and the history out of comments. They go in the commit.
